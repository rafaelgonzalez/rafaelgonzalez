I’ve moved off GitHub. 👋

You can [find me on Codeberg](https://codeberg.org/rafaelgonzalez), but most of my code will be on a self-hosted Forgejo instance anyway, to keep my code away from LLM creeps.

I’ve had enough of GitHub’s overall enshittification and degradation of service[^1][^6]. I’m tired of being tied to corporations like ~~Microsoft~~ Microslop who actively make software a liability. I’m tired of their evident lack of care for consent, environmental harms and cognitive deskilling[^2][^3][^4][^5] when training and deploying their monstrous LLMs. I’m tired of the flood of GenAI slop they have helped unleash that has been so detrimental to open-source projects like curl[^7], zlig[^8], SourceHut[^9] or Ghostty [^10]. And there are many other reasons to move on: the [Give Up GitHub](https://sfconservancy.org/GiveUpGitHub/) initiative covers those at length.

If this sentiment resonates with you, I’d encourage you to consider also moving on if you can. There are several alternatives:

- [Codeberg](https://codeberg.org/), SaaS code forge, operated by a non-profit, funded through donations. It runs on Forgejo.
- [Forgejo](https://forgejo.org/), self-hostable, open-source code forge software. Maintained by the Codeberg non-profit. It is a fork of Gitea.
- [Gitea](https://gitea.com), SaaS and self-hostable open-source code forge software.
- [SourceHut](https://sourcehut.org/), SaaS and self-hostable open-source code forge software.

I will still engage with GitHub where absolutely necessary, like reporting bugs on projects still hosted on the platform. But I won’t be hosting my own code there anymore.

As for the scourge of GenAI itself, my advice would be to tune into folks like [Karen Hao](https://karendhao.com/), Ed Zitron ([blog](https://www.wheresyoured.at/), [podcast](https://www.youtube.com/@BetterOfflinePod)), [Adam Becker](https://freelanceastrophysicist.com/) and [Brian Merchant](https://www.bloodinthemachine.com/). They have kept me sane, and hopefully they will keep you sane too. And if you are being asked to embrace AI, why not [read lots of books](https://www.bloodinthemachine.com/p/the-best-books-films-and-tv-that) about it?

Good luck out there. ✌️
